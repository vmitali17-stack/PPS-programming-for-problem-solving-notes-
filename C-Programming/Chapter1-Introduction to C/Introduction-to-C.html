What is C?

C is a general-purpose, procedural programming language created by Dennis Ritchie in 1972 at Bell Labs, originally to build the UNIX operating system.

It's called a "middle-level" language — it gives you low-level control (like memory access) while still being readable like a high-level language.

Structure of a Program

Every C program follows the same basic skeleton:

// Documentation #include <stdio.h> // header int main() { // entry point int a = 5; // declaration printf("Hello!"); // statement return 0; // exit }

Execution always starts at main() — no matter how big the program is.

Your First Program

#include <stdio.h> int main() { printf("Hello, World!"); return 0; } /* Output: Hello, World! */

printf() shows output. scanf() takes input — and always needs & before the variable name.

✅

Quick Recap

• C was made by Dennis Ritchie in 1972

• Every program needs a main() function

• Code goes: preprocess → compile → link → run

• C is case-sensitive, statements end with ;

• printf = output, scanf = input
