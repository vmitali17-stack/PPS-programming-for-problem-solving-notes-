Foundations

1️⃣ Introduction to C

What is C? C is a general-purpose, procedural (step-by-step instruction based) programming language created by Dennis Ritchie in 1972 at Bell Labs. It's called the "mother of all languages" because C++, Java, Python's interpreter, and even parts of Windows/Linux are built using C concepts.
Why you're learning it first: C teaches you exactly how a computer thinks (memory, variables, execution order) with no hidden magic. Once C clicks, every other language (Python, Java, C++) feels easier because they all borrow C's core ideas.

Key Features

FeatureMeaning
ProceduralCode runs top to bottom, in the order you write it, using functions
Fast / Low-level accessLets you directly control memory (via pointers)
PortableSame C code can run on Windows, Linux, Mac with minor changes
StructuredPrograms are broken into functions/blocks — easy to manage
Rich LibraryBuilt-in functions for math, strings, files, etc. (e.g. stdio.h)
Used for: Operating systems (Linux kernel), embedded systems (microcontrollers, IoT devices), device drivers, game engines, and as the base for learning DSA (Data Structures & Algorithms) in interviews.

2️⃣ Structure of a C Program

Every C program follows this skeleton:

// 1. Preprocessor directives — tell compiler which libraries to include
#include <stdio.h>

// 2. Global declarations (optional) — visible to whole program
int globalMarks = 90;

// 3. main() function — execution ALWAYS starts here
int main() {
    // 4. Local variable declarations
    int age = 18;

    // 5. Statements / logic
    printf("Hello Mitali! Age: %d", age);

    // 6. Return statement — tells OS the program ended successfully
    return 0;
}
Hello Mitali! Age: 18

Line-by-line meaning

  • #include <stdio.h> → gives access to standard input output functions like printf, scanf
  • int main() → the compulsory entry point; int means it returns a whole number to the OS
  • { } → curly braces mark the start/end of a block of code
  • ; → every statement ends with a semicolon (forgetting this is the #1 beginner error)
  • return 0; → 0 means "program ran successfully", non-zero usually means error

3️⃣ How C Code Runs (Compilation Process)

C is a compiled language — your code is fully translated into machine code (0s and 1s) before it runs, unlike Python which is interpreted line-by-line.

4 Stages:

StageWhat HappensFile Produced
1. PreprocessingHandles lines starting with # (like #include, #define).i
2. CompilationConverts C code to Assembly language.s
3. AssemblyConverts Assembly to machine code (object code).o / .obj
4. LinkingCombines your object code with library code to make final program.exe
Compilers you'll use: GCC (most common, free), Turbo C (old, still used in some colleges), or online compilers like OneCompiler / Compiler Explorer.

5️⃣ Variables & Constants

Variable = a named memory location whose value CAN change. Constant = a value that CANNOT change once set.

Naming Rules

  • Can contain letters, digits, underscore — must start with letter or _
  • Cannot use C keywords (int, return, etc.) as names
  • Case sensitive → Age and age are different

Declaring Constants

// Method 1: const keyword
const float PI = 3.14;

// Method 2: #define (preprocessor, no memory used, no semicolon)
#define RATE 5
Why constants matter: If a value like tax rate is used 50 times in code and it changes, you edit ONE line instead of 50 — reduces bugs.

6️⃣ Input & Output

printf() → prints output to screen. scanf() → reads input from user. Both come from stdio.h.
int main() {
    int marks;
    printf("Enter your marks: ");
    scanf("%d", &marks);   // & means "address of" marks
    printf("You entered: %d", marks);
    return 0;
}
Why the & in scanf? scanf needs the actual memory address of the variable to store the input directly into it — not a copy. (Not needed for strings, since an array name is already an address — covered in Arrays section.)

7️⃣ Operators

Arithmetic

+ - * / %

% = modulus (remainder) → 10 % 3 = 1

Relational

== != > < >= <=

Result is always 1 (true) or 0 (false)

Logical

&& (AND), || (OR), ! (NOT)

Assignment

= += -= *= /= %=

Increment/Decrement

++ and -- (pre and post)

Bitwise

& | ^ ~ << >> (work on binary bits)

Pre vs Post increment: ++a increases first, then uses value. a++ uses value first, then increases. Example: if a=5, printf("%d", a++) prints 5 but a becomes 6 right after.

8️⃣ Decision Making — if / else / switch

Lets the program choose a path based on a condition (true/false).
int marks = 75;
if (marks >= 90) {
    printf("Grade: A");
} else if (marks >= 75) {
    printf("Grade: B");
} else {
    printf("Grade: C");
}
Grade: B

switch — cleaner alternative for many fixed choices

int day = 3;
switch(day) {
    case 1: printf("Monday"); break;
    case 2: printf("Tuesday"); break;
    case 3: printf("Wednesday"); break;
    default: printf("Invalid day");
}
Wednesday
Never forget break! Without it, execution "falls through" and runs the next cases too.

9️⃣ Loops

Loops repeat a block of code until a condition becomes false — used to avoid writing repetitive code.

for loop — best when you know how many times to repeat

for (int i = 1; i <= 5; i++) {
    printf("%d ", i);
}
1 2 3 4 5

while loop — best when repetition depends on a condition, count unknown

int i = 1;
while (i <= 5) {
    printf("%d ", i);
    i++;
}

do-while — runs the body AT LEAST ONCE, condition checked after

int i = 1;
do {
    printf("%d ", i);
    i++;
} while (i <= 5);
StatementEffect
breakExits the loop immediately
continueSkips current iteration, goes to next
Data Structures

🔟 Arrays

An array stores multiple values of the same type in one variable, in continuous memory locations, accessed using an index (starting from 0).
int marks[5] = {90, 85, 76, 60, 99};
printf("%d", marks[0]);  // prints 90 (first element)
printf("%d", marks[4]);  // prints 99 (last element)

// Looping through an array
for(int i = 0; i < 5; i++){
    printf("%d ", marks[i]);
}
90 85 76 60 99

2D Arrays (like a table/grid — used for matrices)

int matrix[2][3] = { {1,2,3}, {4,5,6} };
printf("%d", matrix[1][2]); // row 1, col 2 -> prints 6
Why it matters: Arrays are the base of almost every DSA topic (stacks, queues, sorting, searching) you'll study for placements.

1️⃣2️⃣ Functions

A function is a reusable block of code that performs one task. main() itself is a function — every C program has at least one.
// Function declaration (prototype)
int add(int a, int b);

int main() {
    int result = add(5, 3);  // function CALL
    printf("%d", result);
    return 0;
}

// Function definition
int add(int a, int b) {
    return a + b;
}
8

Why break code into functions?

  • Reusability — write once, call many times
  • Easier debugging — test small pieces separately
  • Readability — main() stays short and clear

Parameter Passing

1️⃣3️⃣ Recursion

A function that calls itself to solve a smaller version of the same problem, until it reaches a "base case" that stops it.
int factorial(int n) {
    if (n == 0) return 1;      // base case — stops recursion
    return n * factorial(n - 1); // recursive call
}
// factorial(4) = 4*3*2*1*1 = 24
Why learn it: Recursion is essential for tree/graph traversal, sorting algorithms (merge sort, quick sort), and is a favorite interview/exam topic.
Golden rule: Every recursive function MUST have a base case, or it runs forever and crashes (stack overflow).

1️⃣5️⃣ Pointers

A pointer is a variable that stores the memory address of another variable, instead of a normal value.
int age = 20;
int *p = &age;   // p stores the ADDRESS of age

printf("%d", age);    // 20 (value)
printf("%p", &age);   // e.g. 0x7ffe... (address)
printf("%d", *p);     // 20 (*p means "value AT this address" - dereferencing)
SymbolMeaning
&"Address of" — gives the memory location of a variable
*"Value at address" (dereference) OR declares a pointer variable
Why pointers are powerful (and scary at first): They let a function actually modify the original variable (call by reference), let you build dynamic data structures (linked lists, trees), and let you manage memory manually.
Beginner tip: Read int *p as "p is a pointer that will point to an int". Practice tracing address vs value on paper — this is where most Sem-1 students get confused, so go slow here.
Core Concept

1️⃣6️⃣ Structures & Unions

Structure groups different data types together under one name — useful for representing a real-world entity (like a Student with name, roll no, marks).
struct Student {
    char name[20];
    int roll;
    float marks;
};

int main() {
    struct Student s1 = {"Mitali", 101, 92.5};
    printf("%s %d %.1f", s1.name, s1.roll, s1.marks);
    return 0;
}
Mitali 101 92.5
Union looks similar but all members share the same memory location — so only one member holds a valid value at a time (saves memory).
StructureUnion
Each member has own memoryAll members share one memory block
Size = sum of all membersSize = size of largest member
All values usable simultaneouslyOnly last-assigned value is valid

1️⃣7️⃣ Dynamic Memory Allocation

Normally array size is fixed at compile time. DMA lets you request memory while the program is running, from stdlib.h.
FunctionUse
malloc(size)Allocates memory, contains garbage values
calloc(n, size)Allocates memory for n elements, initialized to 0
realloc(ptr, size)Resizes previously allocated memory
free(ptr)Releases memory back to the system
int *arr = (int*) malloc(5 * sizeof(int));
if (arr == NULL) { printf("Memory not allocated"); }
arr[0] = 10;
free(arr);  // always free what you malloc — prevents "memory leaks"

1️⃣8️⃣ File Handling

Lets a program store data permanently on disk (in a file) instead of losing it when the program ends.
FILE *fp = fopen("data.txt", "w");  // open in WRITE mode
fprintf(fp, "Mitali scored 92");
fclose(fp);                              // ALWAYS close after use

FILE *fp2 = fopen("data.txt", "r");  // open in READ mode
char buffer[100];
fscanf(fp2, "%[^\n]", buffer);
printf("%s", buffer);
fclose(fp2);
ModeMeaning
"r"Read (file must exist)
"w"Write (creates new / erases existing)
"a"Append (adds to end without erasing)

🎯 Common Confusions & Quick Exam Tips

ConfusionClarification
= vs === assigns a value; == compares two values
char c='A' vs char s[]="A"First is one character; second is a 2-char array ('A' + '\0')
Array vs PointerAn array name decays into a pointer to its first element, but an array itself is a fixed block, a pointer can be reassigned
while vs do-whilewhile checks condition BEFORE running; do-while runs body once, THEN checks
Global vs Local variableGlobal: declared outside all functions, accessible everywhere. Local: declared inside a function, accessible only there
malloc vs callocmalloc = uninitialized garbage memory; calloc = memory pre-set to zero
How to "own" this topic in a viva/interview: For every concept, be able to say in one line: (1) what it is, (2) a tiny code example, (3) why/where it's used. That 3-step explanation is exactly what examiners and interviewers want — you now have all three for every topic above.
Practice plan: Don't just read — type every example above yourself in a compiler, change the numbers, and predict the output before running it. That's how this becomes permanent knowledge instead of just notes.
